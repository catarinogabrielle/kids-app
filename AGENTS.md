# Regras do Projeto (kids-app)

- **Versionamento e Deploy**: Sempre comitar e enviar as alterações para o repositório remoto no GitHub na branch `main` (`git push origin main`) após a conclusão das tarefas ou melhorias validadas.
- **Padrão de Mensagem de Commit**: Utilizar Conventional Commits (`feat:`, `fix:`, `style:`, `refactor:`, etc.).
